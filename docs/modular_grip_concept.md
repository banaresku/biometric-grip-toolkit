# Modular Adjustable Grip
## FWB 800X — Universal Sport Grip System

---

## Концепт

Универсальная рукоятка с непрерывной механической регулировкой вместо биометрического STL под каждого стрелка.

Стрелок крутит винты → модули двигаются → итоговое положение = индивидуальный профиль.

```
КОЛОДКА (base) — печатается один раз
    ├── Монтаж FWB 800X (фиксированный)
    └── Посадочные места под 5 модулей

МОДУЛИ (adjustable) — регулируются винтами
    ├── M1: Palm shelf     (вперёд/назад)
    ├── M2: Thumb rest     (высота + угол)
    ├── M3: Backstrap      (радиус прижима)
    ├── M4: Pinky shelf    (высота)
    ├── M5: Trigger reach  (толщина проставки)
    └── M6: Palm swell     (глубина, PA12/TPU вставка)
```

**Рабочий диапазон каждого модуля: ±8мм / ±15°**

После настройки положения винтов = параметры для финальной монолитной версии (опционально).

---

## Размерная сетка

Каждый размер — Voronoi, каждый с модулями. Разница только в базовой колодке.

Модули имеют изначальный зазор ±3мм — чтобы можно было уйти в меньший или больший соседний размер. Рука с нестандартными пропорциями попадает в перекрытие соседних размеров и находит своё через модули.

```
Размер    Центр    Диапазон модулей    Покрытие
──────────────────────────────────────────────
XXS       70мм     ±3мм               67..73мм
XS        75мм     ±3мм               72..78мм
S         81мм     ±3мм               78..84мм
M         88мм     ±3мм               85..91мм
L         95мм     ±3мм               92..98мм
XL        101мм    ±3мм               98..104мм
```

Соседние размеры перекрываются — ошибиться на один размер не критично.

## Два пути подбора

### Путь А — Universal (без биометрии)

```
Выбрать ближайший размер по ширине ладони
      ↓
Напечатать колодку выбранного размера
      ↓
Физический подбор через модули (±3мм)
      ↓
Готово — уже лучше стандартной рукоятки
```

Для большинства стрелков, быстрый старт, минимум инструментов.

### Путь Б — Fitted (с биометрией)

```
BiometriScan (фото или скан)
      ↓
Автоматический выбор размера колодки
      ↓
Параметрический STL под биометрию
      ↓
Voronoi + модули ±1-2мм доводка
      ↓
Микронастройка под подкожную анатомию
```

Для серьёзного спортсмена. Биометрия даёт внешнюю геометрию, модули закрывают то что под кожей.

### Путь В — Custom (итерация А→Б)

A+Б композит — для тех кому не нравится Квазимодо с торчащими винтами.

```
Путь А: физический подбор модулями
      ↓
Снять параметры с модулей (штангель → JSON)
      ↓
Путь Б: финальный монолитный STL по этим параметрам
      ↓
Voronoi финал без регулировочных модулей
```

Физически нашёл через модули — зафиксировал в чистом монолите. Для олимпийского уровня.

---

> **Примечание:** Модули не для подбора размера — размер это база (как обувь 42 или 43). Модули только для подгонки внутри размера и перекрытия с соседним (как стелька). Большой диапазон модулей → большие зазоры → люфт → нарушение концепта микронастройки.

### Зоны колодки

```
         [M2 Thumb rest]
              |
[M5]──[КОЛОДКА]──[M1 Palm shelf]
              |
         [M3 Backstrap]
              |
         [M4 Pinky shelf]
              |
         [FWB mount]
```

### Требования к колодке

- Материал: PETG или ASA (жёсткость, не хрупкий)
- Стенки: ≥3мм везде, монтажная зона ≥5мм
- Посадки под модули: допуск H7/f7 (скользящая) = +0.2мм к номиналу
- Направляющие: T-slot профиль 6мм или прямоугольный паз

### Монтажные точки FWB 800X

```
! Обязательно вымерять с оригинала !

fwb_screw_1_y    = ?мм от низа рукоятки
fwb_screw_2_y    = ?мм от низа рукоятки
fwb_screw_dia    = M4 (предположительно)
fwb_rail_width   = ?мм
fwb_rail_depth   = ?мм
```

## Модули

### M1 — Palm Shelf (подпорка под ладонь)

**Функция:** регулирует насколько рукоятка выступает под ладонь (вперёд/назад).

```
Движение: линейное, перпендикулярно оси рукоятки
Диапазон: 0..+12мм от поверхности колодки
Механика: винт М3×30 толкает модуль, пружина возвращает
Фиксация: контргайка М3 или нейлоновая вставка
```

**Конструкция:**
```
Колодка имеет паз 8×8мм
Модуль — прямоугольный слайдер в пазу
Регулировочный винт входит сбоку
Поверхность контакта — скруглённая (R15)
```

---

### M2 — Thumb Rest (упор большого пальца)

**Функция:** регулирует позицию и угол упора для большого пальца.

```
Движение 1: высота (вверх/вниз) 0..+15мм
Движение 2: угол поворота ±20°
Механика:   два независимых винта М3
Фиксация:   оба с нейлоновой вставкой (самостопорящиеся)
```

**Конструкция:**
```
Вертикальная направляющая на колодке
Поворотный шарнир на слайдере (ось М4)
Стопорный винт на шарнире
Поверхность упора — эргономичная, R8
```

---

### M3 — Backstrap (тыльник)

**Функция:** регулирует степень прижима тыльника к ладони (полнота хвата).

```
Движение: линейное назад/вперёд
Диапазон: 0..+10мм
Механика: центральный винт М4×40 с широкой шляпкой
Фиксация: нейлоновая вставка в гайке
```

**Конструкция:**
```
Тыльник на двух параллельных направляющих (анти-ротация)
Регулировочный винт по центру
Поверхность — изогнутая, повторяет ладонь
```

---

### M4 — Pinky Shelf (упор под мизинец)

**Функция:** высота нижнего упора под мизинец.

```
Движение: вертикальное
Диапазон: 0..+10мм
Механика: один винт М3×20
Фиксация: нейлоновая вставка
```

**Конструкция:**
```
Простейший вертикальный слайдер
Профиль полки — скруглённый снизу (комфорт)
```

---

### M5 — Trigger Reach (проставка указательного)

**Функция:** регулирует расстояние до спускового крючка путём изменения толщины передней части рукоятки.

```
Движение: линейное вперёд
Диапазон: 0..+8мм
Механика: клиновая вставка или прямой слайдер
Фиксация: боковой винт М3
```

**Конструкция:**
```
Передняя панель рукоятки — съёмная
Слайдер двигает её вперёд
Или: набор сменных проставок 2/4/6/8мм (проще в печати)
```

> **Примечание по M5:** для trigger reach дискретные проставки надёжнее — нет смещения под нагрузкой.

## Механика направляющих

### Вариант А — T-slot паз (рекомендуется)

```
Паз в колодке: T-образный профиль
Модуль: T-образный хвост + скользящая посадка
Допуск: 0.2мм на сторону

Плюсы: надёжная анти-ротация, стандартная геометрия
Минусы: сложнее печатать точно
```

```
  ┌───┐
  │   │  ← ширина 6мм
──┤   ├──
  │   │  ← глубина 8мм
  └───┘
    T-slot сечение
```

### Вариант Б — Двойная прямоугольная направляющая

```
Два паза 3×3мм с разносом
Модуль на двух штырях
Проще в печати, достаточно для данных нагрузок

Допуск штырь/паз: +0.25мм
```

### Допуски для FDM печати

```
Скользящая посадка:  +0.20мм на сторону (проверить на тесте!)
Резьбовые вставки:   M3 heat-set insert в колодку (не нарезать в PETG)
Минимальная стенка направляющей: 1.8мм
```

## Фиксация положения

### Heat-set inserts (рекомендуется)

Все резьбы под регулировочные винты — через термовставки M3.
Не нарезать резьбу напрямую в PETG — разбивается за 10-15 циклов.

```
Вставка: M3×4мм heat-set (knurled brass)
Установка: паяльник 200°C, вдавить заподлицо
```

### Самостопорящиеся гайки

На всех регулировочных винтах — нейлоновые вставки или Nord-Lock шайбы.
Обычные гайки сползают от вибрации при стрельбе.

## Протокол подбора рукоятки — объективные маркеры

Протокол для тренера. Никаких субъективных оценок — только наблюдаемые факты.

Инструменты: рукоятка на винтовке, набор цилиндров, штангенциркуль, телефон для фото сбоку.

---

### Шаг 0 — Стартовая позиция

Все модули в среднем положении (половина диапазона). Стрелок берёт винтовку в естественный хват, закрывает глаза, открывает — фиксируем как лежит рука.

---

### M5 — Trigger Reach (первым всегда)

**Маркер:** Где касается спусковой крючок относительно указательного пальца.

```
✓ ПРАВИЛЬНО:  крючок касается середины подушечки первой фаланги
✗ МАЛО:       крючок упирается в сустав между 1й и 2й фалангой
✗ МНОГО:      крючок касается кончика пальца или ногтя
```

Как проверить: посмотреть сбоку. Или отметить маркером точку касания, сфотографировать.

Регулировка: двигать M5 пока не попадёт в правильную зону. Зафиксировать.

---

### M3 — Backstrap (второй)

**Маркер:** Контакт тыльника с ладонью в зоне hypothenar (мясистая часть под мизинцем).

```
✓ ПРАВИЛЬНО:  тыльник касается всей зоны hypothenar без зазора,
              запястье прямое (не согнуто вперёд/назад)
✗ МАЛО:       зазор между тыльником и ладонью виден сбоку
✗ МНОГО:      запястье отогнуто назад, рука "сломана" в запястье
```

Как проверить: полоска бумаги не должна входить между тыльником и ладонью. Сфотографировать сбоку — запястье и предплечье в одну линию.

---

### M1 — Palm Shelf (третий)

**Маркер:** Положение складки между большим и указательным пальцем (thenar web) относительно верхнего края рукоятки.

```
✓ ПРАВИЛЬНО:  thenar web лежит на верхнем крае без давления,
              большой палец не поднят усилием
✗ МАЛО:       thenar web висит в воздухе, рука "проваливается"
✗ МНОГО:      thenar web сдавлен, большой палец вынужден отводиться
```

Как проверить: попросить стрелка поднять большой палец вверх — он должен подниматься свободно без усилия со стороны рукоятки. Сфотографировать сверху.

---

### M2 — Thumb Rest (четвёртый)

**Маркер:** Контакт большого пальца с упором.

```
✓ ПРАВИЛЬНО:  подушечка большого пальца (не сустав, не ноготь)
              лежит на упоре, большой палец расслаблен
              угол большого пальца ≈ параллельно стволу
✗ ВЫСОКО:     большой палец согнут вниз чтобы дотянуться
✗ НИЗКО:      большой палец согнут вверх, мышца напряжена
✗ УГОЛ:       большой палец отведён в сторону от ствола > 20°
```

Как проверить: попросить стрелка пошевелить большим пальцем — должен двигаться свободно. Фото сбоку — угол большого пальца относительно оси ствола.

---

### M6 — Palm Swell (глубина под ладонь)

**Функция:** регулирует выпуклость боковой поверхности рукоятки в зоне контакта с ладонью.

```
Движение: перпендикулярно оси рукоятки (Z)
Диапазон: 0..+8мм
Механика: один винт М3, толкает вставку изнутри
Фиксация: нейлоновая вставка
```

**Материал вставки — PA12 или TPU 95A (Shore D70-75):**

Не мягкая накладка — упругая геометрия. Форму держит жёстко, под давлением ладони микродеформация 0.1-0.3мм, при отпускании возвращается. Визуально и тактильно — твёрдая деталь. Соответствует требованиям ISSF.

Двойной эффект: винтом грубая настройка глубины, материалом пассивная тонкая подстройка под конкретную ладонь.

**Зона действия:** thenar eminence — основание большого пальца, мясистая часть ладони. Именно здесь нужна адаптация под глубину — в других зонах регулировка достигается поворотом и перемещением других модулей.

## Материальная философия модулей

```
ЖЁСТКИЕ (PETG / ASA):
  Колодка (base)        — вся структура
  Направляющие          — точность посадки
  M1 Palm shelf         — опорная нагрузка
  M4 Pinky shelf        — опорная нагрузка
  M5 Trigger reach      — точность важнее комфорта

УПРУГИЕ (PA12 / TPU 95A, Shore D70-75):
  M6 Palm swell вставка — единственная активно гнущаяся зона
                          основание большого пальца,
                          пассивная подстройка под ладонь

КОМБИНИРОВАННЫЕ (жёсткая основа + упругая контактная поверхность):
  M2 Thumb rest         — жёсткий корпус, PA12 подушечка
  M3 Backstrap          — жёсткий корпус, PA12 поверхность
```

**Принцип:** только одна зона активно использует упругость материала — palm swell. Всё остальное жёсткое, регулировка только геометрическая. Это соответствует духу ISSF правил и физически обосновано — большой палец, пальцы, мизинец находят положение через повороты модулей, не через деформацию материала.

**ISSF граница:** мягкие накладки (foam, резина, гель) — запрещены. PA12/TPU D70+ которые держат форму — не накладки, упругая конструктивная деталь. Разница принципиальная.

**Маркер:** Контакт мизинца с полкой.

```
✓ ПРАВИЛЬНО:  нижняя фаланга мизинца лежит на полке,
              мизинец не свисает вниз, не поджат вверх
✗ НИЗКО:      мизинец свисает ниже полки, нет упора
✗ ВЫСОКО:     мизинец поджат к безымянному пальцу, полка не используется
```

Как проверить: визуально снизу и сбоку. Мизинец должен лежать горизонтально.

---

### Финальная проверка — контрольный хват

После настройки всех модулей:

```
1. Стрелок закрывает глаза, кладёт винтовку, берёт хват
2. Открывает глаза — тренер проверяет все 5 маркеров одновременно
3. Повторить 5 раз → если все 5 раз маркеры сходятся → OK
4. Если один маркер нестабилен → возвращаемся к тому модулю

Критерий принятия: 5 из 5 повторов все маркеры в норме
```

3. Записать в shooter_profile.json

## Физиология и психосоматика хвата

### Почему потеет рука на соревнованиях

Потоотделение в стрелковом спорте — не только термальное. Соревновательный стресс → адреналин → потоотделение независимо от температуры. У 10м стрелков это выражено особенно — пауза между выстрелами, концентрация, накопление напряжения. "Ощущение что тонешь в цементе" — психосоматика, не физиология.

### Что реально работает в объёме рукоятки

Chimney effect и принудительная конвекция внутри рукоятки — физически не реализуемы. Объём слишком мал, высота недостаточна. Только пассивная диффузия по градиенту температуры.

```
НЕ работает в рукоятке:   конвекция, chimney effect, каналы
РАБОТАЕТ:                 механический дренаж через Voronoi геометрию
```

### Механический дренаж — как это работает

Не каналы. Чистая геометрия:

```
Ладонь давит на рёбра Voronoi
      ↓
Между ладонью и рёбрами нет сплошного контакта
      ↓
Влага не накапливается под ладонью —
уходит в открытые ячейки
      ↓
Из ячеек испаряется или стекает вниз
```

Аналогия — протектор шины. Резина контактирует с дорогой по рёбрам, вода уходит в канавки.

### Психологический аспект

Субъективная сухость поверхности = ощущение контроля = снижение тревоги = меньше адреналина = меньше потоотделения. Петля с положительной обратной связью.

Стабильное тактильное ощущение хвата через стресс — психологический якорь. Рукоятка которая "держит" даже в момент пика напряжения снижает когнитивную нагрузку на удержание.

Это нигде не задокументировано производителями рукояток — но очевидно любому стрелку который стрелял на соревнованиях.

### Размер ячеек Voronoi под дренаж

```
Мелкая сетка (scale 6+):   больше рёбер → лучше сцепление
                            меньше ячейки → хуже дренаж

Крупная сетка (scale 3-4): меньше рёбер → меньше сцепление
                            крупнее ячейки → лучше дренаж влаги

Оптимум:                   scale 4-5, подбирается под
                            размер ладони стрелка
```

Крупная ладонь — крупнее ячейки. Мелкая ладонь — мельче. Это параметр VoroShell который стоит связать с размером рукоятки.

### Позиция

Стрелковый спорт уже разделён по финансовому признаку — Morini, Steyr, Pardini доступны не всем. Цель проекта не создать технологическое превосходство, а выровнять возможности.

Автоматизированный pipeline под открытой лицензией даёт любому клубу — в Молдове, Бразилии, Казахстане — тот же инструмент подбора что используют богатые федерации.
