# Product Decomposition
## Три независимых инструмента / Three Independent Tools

---

## Концепция

Вместо монолитного проекта под конкретный инструмент — три независимых переиспользуемых инструмента с широкой областью применения.

Каждый инструмент решает одну задачу и решает её хорошо. Вместе они образуют pipeline. По отдельности — самостоятельная ценность.

```
BiometriScan  ──→  ParamGrip  ──→  VoroShell
   (данные)        (геометрия)      (структура)
```

Публикация как open source метода = prior art. После публикации никто не сможет запатентовать этот подход.

---

## Инструмент 1 — BiometriScan

### Что делает

Извлекает биометрические параметры руки из 2D фото с компенсацией всех искажений.

### Входные данные

```
Фото 1: ладонь вверх на ChArUco пластине
Фото 2: хват калиброванного цилиндра, вид сбоку
Опционально: PLY/OBJ скан руки
```

### Выходные данные

```json
{
  "palm_width_max": 87.3,
  "palm_length": 112.5,
  "grip_diameter": 36.0,
  "thumb_angle_deg": 38.0,
  "trigger_reach_est": 55.0,
  ...
}
```

### Технологии

```
OpenCV      — детектирование ChArUco, гомография
MediaPipe   — 21 landmark руки
Open3D      — анализ 3D скана (опционально)
Python      — всё склеивает
```

### Ключевые решения

- **ChArUco пластина** вместо бумажной рамки — жёсткая, мат поверхность, без бликов
- **Гомография** корректирует перспективу — камера может стоять под углом до 40°
- **Калиброванный цилиндр** в фото 2 — физический маркер диаметра хвата, детектируется через HoughCircles
- **Wrist baseline** на пластине — физический бортик для воспроизводимой укладки руки
- **Оси пальцев** на пластине — объективные маркеры для тренера

### Применения (за пределами оружия)

```
Инструменты (молотки, стамески, ножи)
Велосипедные ручки и грипсы
Медицинские приборы (скальпели, эндоскопы)
Геймпады и джойстики
Спортивный инвентарь (ракетки, клюшки)
Протезирование (данные для тибии/кисти)
Промышленные рукоятки (виброинструмент)
```

### Статус конкурентов

MeshPro использует фото руки на референсном листе + закрытую AI модель.
BiometriScan — открытый алгоритм, воспроизводимый метод, без чёрного ящика.

## Инструмент 2 — ParamGrip

### Что делает

Генерирует параметрическую 3D модель изделия под руку на основе биометрических данных.
Монтажные точки фиксированы. Эргономическая геометрия — параметрическая.

### Входные данные

```
grip_params.json     — из BiometriScan
mount_points.json    — монтажные точки конкретного изделия
grip_template.FCStd  — базовый шаблон FreeCAD
```

### Выходные данные

```
grip_model.step   — редактируемая геометрия
grip_model.stl    — для печати
```

### Технологии

```
FreeCAD       — параметрическое ядро, Spreadsheet workbench
Python API    — автоматическая загрузка параметров
Fusion 360    — органический loft, T-Splines (опционально)
```

### Архитектура

```
BiometriScan JSON
      ↓
FreeCAD Spreadsheet (автозагрузка через Python)
      ↓
Параметрические сечения (Sketcher)
      ↓
Loft через сечения
      ↓
Монтажные точки (фиксированные constraints)
      ↓
STEP экспорт
```

### Параметры модели

```
Эргономические (из BiometriScan):
  palm_width, grip_depth, thumb_angle,
  palm_swell_position, trigger_reach,
  grip_height, wrist_width

Монтажные (из mount_points.json, фиксированные):
  screw_positions, rail_geometry,
  mounting_face_offset
```

### Применения

```
Спортивное оружие     — рукоятки пистолет/винтовка
Ручной инструмент     — персонализированные рукояти
Велосипед             — грипсы под конкретную ладонь
Медтехника            — хирургические инструменты
Ортопедия             — вспомогательные рукоятки
Промышленность        — виброгасящие рукоятки
```

### Расширяемость

Новый тип изделия = новый `mount_points.json` + новый шаблон.
Биометрический pipeline не меняется.

## Инструмент 3 — VoroShell

### Что делает

Накладывает Voronoi / lattice структуру на произвольный меш с сохранением критических зон (посадки, отверстия, монтажные поверхности).

### Входные данные

```
mesh.stl / mesh.obj      — исходный меш
zones.json               — маска зон (solid vs lattice)
voronoi_params.json      — параметры паттерна
```

### Выходные данные

```
mesh_voronoi.stl   — готово к печати
```

### Технологии

```
Blender 4.x          — основная среда
Geometry Nodes       — генерация паттерна
Python (bpy)         — автоматизация и маскирование зон
Meshmixer            — альтернативный путь (быстрее, меньше контроля)
```

### Параметры паттерна

```
voronoi_scale        — размер ячеек (мм)
voronoi_randomness   — хаотичность (0.0 - 1.0)
wall_thickness       — толщина рёбер (мм, минимум 1.5)
solid_zones          — список зон без паттерна
transition_width     — ширина перехода solid→lattice (мм)
```

### zones.json пример

```json
{
  "solid_zones": [
    {"name": "mounting_face", "type": "bbox",
     "min": [0, 0, 0], "max": [20, 5, 30]},
    {"name": "screw_holes", "type": "cylinder_radius",
     "centers": [[10, 0, 15], [10, 0, 45]], "radius": 6}
  ],
  "lattice_zones": [
    {"name": "grip_surface", "type": "remainder"}
  ]
}
```

### Физиология хвата — почему Voronoi

```
Равномерная вентиляция:
  → нет локального градиента температуры
  → потоотделение равномерное, не концентрируется

Точечный контакт рёбер:
  → пот уходит в ячейки, не создаёт плёнку
  → сцепление на влажной руке выше чем сплошной материал

Распределение давления:
  → рёбра создают равномерные точки давления
  → нет зон застоя крови при длительном хвате
```

Эти свойства подтверждены коммерчески (MeshPro используют олимпийские чемпионы).

### Применения

```
Спортивные рукоятки   — основное
Велошлемы             — внутренняя структура
Медицинские ортезы    — облегчение + вентиляция
Корпуса электроники   — теплоотвод + вес
Архитектурные модели  — эстетика + структура
Любой меш             — универсально
```
